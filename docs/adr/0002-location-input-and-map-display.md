# ADR 0002: 位置入力と地図表示の分離

## 状態

採用

## 判断

- 地図を位置入力には使用しない
- 位置はスポット名称検索の候補選択、または緯度・経度の直接入力で登録する
- 名称検索は初期実装では公開Nominatimをサーバー経由で利用する
- 公開Nominatimでは逐次オートコンプリートを行わず、利用者が検索ボタンを押した場合だけ検索する
- サーバー側で検索を1秒に1回以下へ制限し、同一検索結果を24時間キャッシュする
- 保存前の地図はMapLibreによる確認専用表示とする
- スポット詳細は、設定されている場合だけGoogle Maps Embed APIを使用する
- Google Maps Embed APIキーが未設定の場合も、Google Maps URLへのリンクを提供してアプリを利用可能にする
- Embed用キーは他のAPIと共用せず、Maps Embed API制限とWebサイト制限を必須とする

## 理由

地図上の地点クリックは施設そのものを特定できず、利用者に正確な名称や住所を再入力させる可能性がある。名称検索と候補選択を主経路にすることで入力負荷を下げ、緯度・経度の直接入力を残すことで検索に存在しない場所にも対応できる。地図表示と検索サービスを分離し、外部APIが未設定または利用不能でも記録機能が停止しない構成にする。
