# ADR 0001: フェーズ0の暫定設計判断

## 状態

採用（機能実装前に必要に応じて再確認する）

## 判断

- 初期版は個人利用を主目的とするが、全データに将来の所有者を設定できる設計余地を残す
- アプリはレスポンシブWebアプリとし、MVP後にPWA化を検討する
- 開発環境はDocker Composeで統一する
- アプリはNext.jsとTypeScript、DBはPostgreSQL、ORMはPrismaを使用する
- 地図表示はMapLibre GL JSを第一候補とする
- 地図タイルとジオコーディングの提供元は、料金と利用規約を比較してフェーズ2の開始前に決定する
- 写真は1スポット20枚、1ファイル13MB、1回のアップロード合計50MBを上限とする
- 変換後画像は長辺2560px、サムネイルは長辺640pxを暫定値とする
- MVPでは元画像を保持せず、変換後画像のみ保存する
- 住所は手入力可能とし、外部サービス決定後に緯度・経度からの自動取得を追加する
- スポット削除はMVPでは確認後の物理削除とし、バックアップからの復旧を運用手段とする

## 理由

フェーズ0で未決事項をすべて恒久決定するよりも、MVPの実装を進められる安全な初期値を置き、実利用で必要性を確認して変更する方が手戻りを抑えられるため。
